# filemanager_b2_operation (Resource)

## Example Usage

```terraform
# Perform Backblaze B2 operations
resource "filemanager_b2_operation" "upload_backup" {
  operation = "upload"
  service   = filemanager_b2_service.backups.name

  local_path  = "/var/backups/database.sql.gz"
  remote_path = "backups/database-${formatdate("YYYY-MM-DD", timestamp())}.sql.gz"

  content_type = "application/gzip"
}

# Download from B2
resource "filemanager_b2_operation" "download_archive" {
  operation = "download"
  service   = filemanager_b2_service.archives.name

  remote_path = "archives/${var.archive_name}"
  local_path  = "/var/restore/${var.archive_name}"

  create_parent_dirs = true
}

# Copy within B2
resource "filemanager_b2_operation" "archive_log" {
  operation = "copy"
  service   = filemanager_b2_service.logs.name

  remote_path      = "current/app.log"
  copy_destination = "archive/${formatdate("YYYY/MM", timestamp())}/app-${formatdate("DD", timestamp())}.log"
}

# List files in B2 bucket
resource "filemanager_b2_operation" "list_backups" {
  operation = "list"
  service   = filemanager_b2_service.backups.name

  remote_path = "backups/"
  prefix      = "database-"
}
```

Performs Backblaze B2 specific operations on files.

## Schema

### Required

- `file_path` (String) File path within the B2 bucket.
- `operation` (String) Operation to perform: head, copy, get_file_info, update_file_info, hide, update_legal_hold.
- `service` (String) B2 service alias.

### Optional

- `destination_path` (String) Destination path for copy operation.
- `file_info` (Map of String) File info/metadata to update (for update_file_info operation).
- `legal_hold` (Boolean) Legal hold status to set (for update_legal_hold operation).

- `content_type` (String) MIME type of the file.
- `current_file_info` (Map of String) Current file info/metadata from B2.
- `file_id` (String) B2 file ID.
- `file_name` (String) B2 file name.
- `id` (String) Unique identifier for the resource.
- `legal_hold_status` (Boolean) Current legal hold status.
- `server_side_encryption` (String) Server-side encryption algorithm used.
- `upload_timestamp` (Number) Upload timestamp in milliseconds since epoch.
