# filemanager_ftp_service (Resource)

## Example Usage

```terraform
# Configure FTP service
resource "filemanager_ftp_service" "main" {
  name     = "ftp-main"
  host     = var.ftp_host
  port     = 21
  user     = var.ftp_user
  password = var.ftp_password
}

# FTP service with passive mode
resource "filemanager_ftp_service" "passive" {
  name         = "ftp-passive"
  host         = var.ftp_host
  port         = 21
  user         = var.ftp_user
  password     = var.ftp_password
  passive_mode = true
}

# FTPS (FTP over TLS)
resource "filemanager_ftp_service" "ftps" {
  name         = "ftps-secure"
  host         = var.ftps_host
  port         = 990
  user         = var.ftp_user
  password     = var.ftp_password
  use_tls      = true
  implicit_tls = true
}

# SFTP via FTP service
resource "filemanager_ftp_service" "sftp" {
  name        = "sftp-server"
  host        = var.sftp_host
  port        = 22
  user        = var.sftp_user
  private_key = var.sftp_private_key
  protocol    = "sftp"
}
```

Configures an FTP/FTPS service for remote file operations.

## Schema

### Required

- `host` (String) FTP server hostname or IP address.

### Optional

- `base_path` (String) Base path prefix for all operations.
- `explicit_tls` (Boolean) Use explicit TLS (AUTH TLS) instead of implicit TLS. Only used when tls_enabled is true.
- `passive_mode` (Boolean) Use passive mode for data connections. Defaults to true.
- `password` (String, Sensitive) FTP password.
- `password_file` (String) Path to file containing FTP password.
- `port` (Number) FTP server port. Defaults to 21.
- `timeout` (String) Connection timeout (e.g., '30s', '1m'). Defaults to 30s.
- `tls_enabled` (Boolean) Enable TLS/SSL for secure FTP (FTPS).
- `username` (String) FTP username. Defaults to 'anonymous'.

### Read-Only

- `connected` (Boolean) Whether the service is currently connected.
- `endpoint` (String) The FTP endpoint in host:port format.
- `id` (String) Unique identifier for the service (format: ftp:host:port).
- `service_type` (String) The type of service (ftp).
