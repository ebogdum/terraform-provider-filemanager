# filemanager_tfvars_file (Resource)


Manages a Terraform `.tfvars` file with native dynamic type support, internal variable interpolation, and merge capabilities.

## Features

- **Native types**: Pass maps, lists, numbers, booleans directly via the `vars` attribute
- **Internal interpolation**: Variables can reference each other using `{{ .var_name }}` syntax
- **Merge with existing**: Preserve unmanaged variables in existing files
- **Variable-level operations**: Set/delete individual variables
- **Dual format**: Output as HCL (`.tfvars`) or JSON (`.tfvars.json`)

## Schema

### Required

- `path` (String) The path where the tfvars file will be created.
- `vars` (Dynamic) Variables to write to the tfvars file. Accepts any Terraform object with native types (strings, numbers, booleans, lists, maps).

### Optional

- `atomic_write` (Boolean) Use atomic write operations.
- `create_parent_dirs` (Boolean) Create parent directories if they don't exist.
- `delete_vars` (List of String) List of variable names to delete from the output (useful with merge_with_existing).
- `directory_permission` (String) Directory permission mode for parent directories.
- `file_permission` (String) File permission mode in octal format.
- `json_format` (Boolean) Output in JSON format (.tfvars.json) instead of HCL (.tfvars).
- `left_delim` (String) Left delimiter for template interpolation.
- `merge_strategy` (String) How to handle conflicts when merging: 'replace' (new vars win) or 'keep_existing' (existing values preserved).
- `merge_with_existing` (Boolean) When true, merges vars with any existing file content instead of replacing entirely.
- `right_delim` (String) Right delimiter for template interpolation.
- `service` (String) Service to use for file operations. Defaults to local filesystem.
- `sort_keys` (Boolean) Sort variable names alphabetically in the output.
- `template_vars` (Map of String) Additional template variables for interpolation. These are available as {{ .key }} in string values but are not written to the output file.
