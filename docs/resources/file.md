# filemanager_file (Resource)

## Example Usage

```terraform
# Create a simple text file
resource "filemanager_file" "example" {
  path    = "/etc/app/config.txt"
  content = "Hello, World!"

  file_permission    = "0644"
  create_parent_dirs = true
}

# Create a configuration file from template
resource "filemanager_file" "config" {
  path    = "/etc/app/app.conf"
  content = <<-EOF
    # Application Configuration
    server_host = ${var.server_host}
    server_port = ${var.server_port}
    debug_mode  = ${var.debug_enabled}
  EOF

  file_permission    = "0600"
  create_parent_dirs = true

  # Enable integrity verification
  atomic_write    = true
  verify_checksum = true
}

# Create a file on remote server via SSH
resource "filemanager_file" "remote" {
  path    = "/opt/app/config.txt"
  content = "Remote configuration"
  service = filemanager_ssh_service.server.id

  file_permission    = "0644"
  create_parent_dirs = true
}
```


Manages a file on the filesystem or remote backend with ACID guarantees.

## Content Sources

You can specify file content using one of three methods (mutually exclusive):

- `content` - Plain text content
- `content_base64` - Base64-encoded content (for binary files)
- `source` - Path to a local file to copy

### Required

- `path` (String) The path where the file will be created.

### Optional

- `atomic_write` (Boolean) Use atomic write operations (temp file + rename).
- `backup` (Boolean) Create a backup before modifying the file.
- `backup_retention` (Number) Number of backup copies to retain.
- `content` (String) The content of the file as a string. Conflicts with content_base64 and source.
- `content_base64` (String) The base64-encoded content of the file. Conflicts with content and source.
- `create_parent_dirs` (Boolean) Create parent directories if they don't exist.
- `directory_permission` (String) Directory permission mode for parent directories in octal format (e.g., "0755").
- `encoding` (String) Character encoding for the file content. Options: utf-8, utf-16, latin1, base64.
- `file_permission` (String) File permission mode in octal format (e.g., "0644").
- `force` (Boolean) Force overwrite if file already exists.
- `gid` (Number) Group ID for file ownership (Unix only).
- `group` (String) Group name for file ownership. Alternative to gid.
- `newline` (String) Newline style for the file. Options: lf, crlf, cr.
- `owner` (String) User name for file ownership. Alternative to uid.
- `service` (String) Service to use for file operations. Defaults to the local filesystem.
- `source` (String) Path to a local file to use as the source. Conflicts with content and content_base64.
- `uid` (Number) User ID for file ownership (Unix only).
- `verify_checksum` (Boolean) Verify file checksum after writing.

### Read-Only

- `absolute_path` (String) The absolute resolved path.
- `directory` (String) The parent directory of the path.
- `extension` (String) The file extension without the leading dot (e.g., 'json').
- `filename` (String) The base name of the file (e.g., 'config.json').
- `id` (String) Unique identifier for the resource.
