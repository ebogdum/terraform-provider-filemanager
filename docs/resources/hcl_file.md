# filemanager_hcl_file (Resource)

## Example Usage

```terraform
# Create an HCL configuration file
resource "filemanager_hcl_file" "config" {
  path = "/etc/app/config.hcl"
  data = {
    server = {
      host = var.server_host
      port = 8080
    }
    database = {
      connection_string = var.db_connection_string
      max_connections   = 100
    }
    features = {
      enable_caching = true
      cache_ttl      = 3600
    }
  }

  create_parent_dirs = true
}

# Create Consul configuration
resource "filemanager_hcl_file" "consul" {
  path = "/etc/consul.d/config.hcl"
  data = {
    datacenter = var.datacenter
    data_dir   = "/opt/consul/data"
    log_level  = "INFO"
    server     = true
    bootstrap_expect = 3
    ui_config = {
      enabled = true
    }
    connect = {
      enabled = true
    }
  }

  create_parent_dirs = true
}

# Create Vault configuration
resource "filemanager_hcl_file" "vault" {
  path = "/etc/vault.d/config.hcl"
  data = {
    storage = {
      consul = {
        address = "127.0.0.1:8500"
        path    = "vault/"
      }
    }
    listener = {
      tcp = {
        address     = "0.0.0.0:8200"
        tls_disable = false
      }
    }
  }

  create_parent_dirs = true
}
```


Manages an HCL file with support for merge and structured content manipulation.

HCL (HashiCorp Configuration Language) is used by Terraform, Consul, Vault, and other HashiCorp tools.

## Content Format

Content should be provided as JSON (use jsonencode()) and will be converted to HCL format.
Blocks are represented as nested objects. Block labels can be specified using a special "__labels__" key.

## Schema

### Required

- `content` (String) The content as a JSON string (use jsonencode()). Will be converted to HCL.
- `path` (String) The path where the HCL file will be created.

### Optional

- `atomic_write` (Boolean) Use atomic write operations.
- `create_parent_dirs` (Boolean) Create parent directories if they don't exist.
- `directory_permission` (String) Directory permission mode for parent directories.
- `file_permission` (String) File permission mode in octal format.
- `merge_strategy` (String) Merge strategy: replace, deep, append, concat, union.
- `merge_with` (String) Additional content to merge (as JSON string). Use jsonencode() to convert HCL.
- `service` (String) Service to use for file operations. Defaults to local filesystem.
- `sort_keys` (Boolean) Sort HCL attribute names alphabetically.

### Read-Only

- `absolute_path` (String) The absolute resolved path.
- `directory` (String) The parent directory of the path.
- `extension` (String) The file extension without the leading dot (e.g., 'json').
- `filename` (String) The base name of the file (e.g., 'config.json').
- `id` (String) Unique identifier for the resource.
- `md5` (String) Deprecated insecure checksum field. Always null.
- `rendered` (String, Sensitive) The rendered HCL content as a string.
- `sha256` (String) SHA-256 checksum of the file content.
- `size` (Number) Size of the file in bytes.
