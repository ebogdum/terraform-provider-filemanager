# filemanager_azure_operation (Resource)

## Example Usage

```terraform
# Perform Azure Blob Storage operations
resource "filemanager_azure_operation" "upload_config" {
  operation = "upload"
  service   = filemanager_azure_service.main.name

  local_path  = "${path.module}/config.json"
  remote_path = "configs/app/config.json"

  content_type = "application/json"
  metadata = {
    environment = var.environment
    deployed_by = "terraform"
  }
}

# Download from Azure
resource "filemanager_azure_operation" "download_artifact" {
  operation = "download"
  service   = filemanager_azure_service.releases.name

  remote_path = "releases/app-${var.version}.tar.gz"
  local_path  = "/var/releases/app-${var.version}.tar.gz"

  create_parent_dirs = true
}

# Copy within Azure container
resource "filemanager_azure_operation" "archive_backup" {
  operation = "copy"
  service   = filemanager_azure_service.backups.name

  remote_path      = "daily/database.sql.gz"
  copy_destination = "archive/${formatdate("YYYY/MM/DD", timestamp())}/database.sql.gz"
}

# List files in container
resource "filemanager_azure_operation" "list_configs" {
  operation = "list"
  service   = filemanager_azure_service.main.name

  remote_path = "configs/"
  prefix      = "app-"
}
```

Performs Azure Blob Storage operations on existing blobs.

## Schema

### Required

- `blob_path` (String) Path to the blob within the container.
- `operation` (String) Operation to perform: head, copy, set_metadata, set_tags, set_access_tier, acquire_lease, release_lease.
- `service` (String) Azure service alias configured in the provider.

### Optional

- `access_tier` (String) Access tier to set: Hot, Cool, or Archive (for set_access_tier operation).
- `destination_path` (String) Destination path for copy operation.
- `lease_duration` (Number) Lease duration in seconds: 15-60 or -1 for infinite (for acquire_lease operation).
- `metadata` (Map of String) Metadata to set on the blob (for set_metadata operation).
- `tags` (Map of String) Tags to set on the blob (for set_tags operation).
