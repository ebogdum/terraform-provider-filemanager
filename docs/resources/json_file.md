# filemanager_json_file (Resource)

## Example Usage

```terraform
# Create a JSON configuration file
resource "filemanager_json_file" "config" {
  path = "/etc/app/config.json"
  data = {
    app_name    = "MyApplication"
    version     = "1.0.0"
    environment = var.environment
    database = {
      host = var.db_host
      port = 5432
      name = "myapp"
    }
    features = {
      logging   = true
      analytics = var.enable_analytics
    }
  }

  pretty_print       = true
  create_parent_dirs = true
}

# Merge with existing JSON file
resource "filemanager_json_file" "merged" {
  path = "/etc/app/settings.json"
  data = {
    new_setting = "value"
    nested = {
      updated_field = "new_value"
    }
  }

  merge      = true
  deep_merge = true
}

# Create JSON file on remote server
resource "filemanager_json_file" "remote_config" {
  path    = "/opt/app/config.json"
  service = filemanager_ssh_service.server.name
  data = {
    server_id = "prod-01"
  }

  pretty_print       = true
  create_parent_dirs = true
}
```

Manages a JSON file with support for deep merge, path queries, and structured content manipulation.

## Schema

### Required

- `content` (String) The JSON content as a string. Use jsonencode() to convert HCL to JSON.
- `path` (String) The path where the JSON file will be created.

### Optional

- `atomic_write` (Boolean) Use atomic write operations.
- `compact` (Boolean) Output compact JSON without whitespace.
- `create_parent_dirs` (Boolean) Create parent directories if they don't exist.
- `directory_permission` (String) Directory permission mode for parent directories.
- `file_permission` (String) File permission mode in octal format.
- `indent` (Number) Indentation spaces for JSON output.
- `merge_strategy` (String) Merge strategy: replace, deep, append, concat, union.
- `merge_with` (String) Additional JSON content to merge with the main content. Use jsonencode() to convert HCL to JSON.
- `service` (String) Service to use for file operations. Defaults to local filesystem.
- `sort_keys` (Boolean) Sort JSON object keys alphabetically.

### Read-Only

- `absolute_path` (String) The absolute resolved path.
- `directory` (String) The parent directory of the path.
- `extension` (String) The file extension without the leading dot (e.g., 'json').
- `filename` (String) The base name of the file (e.g., 'config.json').
- `id` (String) Unique identifier for the resource.
- `md5` (String) MD5 checksum of the file content.
- `rendered` (String, Sensitive) The rendered JSON content as a string.
- `sha256` (String) SHA-256 checksum of the file content.
- `size` (Number) Size of the file in bytes.
