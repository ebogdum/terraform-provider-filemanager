# filemanager_app_config (Resource)

## Example Usage

```terraform
# Create multi-format application configuration
resource "filemanager_app_config" "main" {
  path   = "/etc/app/config"
  format = "auto"  # Automatically detect from filename extension

  data = {
    app = {
      name        = "MyApplication"
      version     = "2.0.0"
      environment = var.environment
    }
    server = {
      host    = "0.0.0.0"
      port    = 8080
      workers = 4
    }
    database = {
      primary = {
        host     = var.db_host
        port     = 5432
        name     = var.db_name
        pool_size = 10
      }
      replica = {
        host     = var.db_replica_host
        port     = 5432
        name     = var.db_name
        pool_size = 5
      }
    }
    cache = {
      enabled = true
      ttl     = 3600
      backend = "redis"
    }
    features = var.feature_flags
  }

  create_parent_dirs = true
}

# Create configuration in specific format
resource "filemanager_app_config" "json_config" {
  path   = "/etc/app/settings.json"
  format = "json"

  data = {
    settings = var.app_settings
  }

  pretty_print       = true
  create_parent_dirs = true
}

# Create configuration with merge capability
resource "filemanager_app_config" "merged" {
  path   = "/etc/app/merged-config.yaml"
  format = "yaml"

  data = {
    new_section = {
      key = "value"
    }
  }

  merge              = true
  deep_merge         = true
  create_parent_dirs = true
}
```


Manages application-specific configuration files with semantic validation and native format output.

Supported applications:
- **nginx** - Nginx web server configuration
- **prometheus** - Prometheus monitoring configuration

## Schema

### Required

- `app` (String) Application type: nginx, prometheus.
- `config` (String) Configuration content as JSON (use jsonencode()). Will be converted to native format.
- `path` (String) The path where the configuration file will be created.

### Optional

- `atomic_write` (Boolean) Use atomic write operations.
- `create_parent_dirs` (Boolean) Create parent directories if they don't exist.
- `directory_permission` (String) Directory permission mode for parent directories.
- `file_permission` (String) File permission mode in octal format.
- `merge_with` (String) Additional configuration to merge (as JSON string).
- `service` (String) Service to use for file operations. Defaults to local filesystem.
- `validate` (Boolean) Validate configuration using app-specific rules.

### Read-Only

- `absolute_path` (String) The absolute resolved path.
- `directory` (String) The parent directory of the path.
- `extension` (String) The file extension without the leading dot (e.g., 'conf').
- `filename` (String) The base name of the file (e.g., 'config.conf').
- `id` (String) Unique identifier for the resource.
- `md5` (String) MD5 checksum of the file content.
- `rendered` (String) The rendered configuration content in native format.
- `sha256` (String) SHA-256 checksum of the file content.
- `size` (Number) Size of the file in bytes.
- `validation_errors` (List of String) List of validation errors/warnings (if any).
